# 实机照片建模参考（v21）

本版按厂家实机照片重新制作主要系列的游戏模型。照片用于观察轮廓、部件连接和相机布置，不是贴图，也不是摄影测量或厂家 CAD。照片不可见的底部、内部结构仍做简化，不应解读为 149 款均已完成逐型号精确复刻。

## 已重做的结构

- ATOM 2 与 ATOM 3：分别采用长平顶壳和隆起额头；不同尺寸云台、前长后短起落脚。
- Mini 4 Pro：白色颊板形成开放相机舱，前额双避障眼。
- Mavic 3 Pro：宽低机壳、上二下一三镜头；Air 3 使用竖向双镜头。
- EVO II / Nano / Lite / Max：厚橙色机身、窄低机身、长电池仓和高机身分别建模；黑色机臂、前后层高、银色相机按系列区分。
- Avata 2 / Neo：开放护桨环与放射肋条笼罩分别建模。
- Phantom / Dreamer：一体 X 臂和机腹高滑橇。
- Inspire 3：H 形碳管侧架、长颈下悬云台和电机脚。
- M300/350 与 M30：高中央机身及四桨臂下布局，对比扁长机身和前上后下旋翼。
- FlyCart / Agras：共轴旋翼和腹部货箱 / 药箱保留独立结构。

真实共用外壳的相机、图传、RTK 或 Cine 变型共用相应机体，仅修改可确认的部件。Mavic 4、Lito、Avata 360、Dragonfish 等未获得可实际检查完整照片的型号仍是资料近似，不能视为照片校准完成。历史型号亦未逐一完成照片校准。
